# 入善 水のききがき帖 — 使い方

GitHub Pages（GitHubの無料公開機能）で動く、入善町の歴史ブログのひな形です。
記事は Markdown（見出しや太字を記号で書くシンプルな書式）のファイルを1つ追加するだけで公開されます。

## 最初の公開（1回だけ、30分ほど）

1. **GitHubのアカウントを作る**（github.com）。ユーザー名はURLに出るので、実名やサイト名に近いものがおすすめです。
2. **新しいリポジトリ（ファイル置き場）を作る**
   - 右上の「＋」→「New repository」
   - 名前の例：`nyuzen-kioku`、公開設定は「Public」
3. **このフォルダの中身をアップロード**
   - リポジトリの画面で「Add file」→「Upload files」
   - フォルダの中身（`_config.yml`、`_layouts` など全部）をドラッグして「Commit changes」
4. **公開をオンにする**
   - 「Settings」→ 左の「Pages」
   - 「Branch」を `main`、フォルダを `/ (root)` にして「Save」
   - 数分後、`https://ユーザー名.github.io/nyuzen-kioku/` で見られるようになります
5. **`_config.yml` を直す**（GitHub上で鉛筆マークから編集できます）
   - 無料アドレスで公開する場合：
     `url: "https://ユーザー名.github.io"`、`baseurl: "/nyuzen-kioku"`
   - 名前や自己紹介も自分の内容に書き換えます

## 独自ドメインを使う場合（あとからでOK）

1. ドメイン会社でドメインを買う（例：`nyuzen-kioku.jp`。料金は会社ごとに確認）
2. GitHubの「Settings」→「Pages」→「Custom domain」にドメインを入力
3. ドメイン会社の画面で、GitHubの案内どおりにDNS（住所の登録）を設定
4. `_config.yml` を `url: "https://nyuzen-kioku.jp"`、`baseurl: ""` に変更
5. 「Enforce HTTPS」にチェック

## 記事の書き方

1. `templates/記事テンプレート.md` をコピーする
2. ファイル名を `年-月-日-英数字の名前.md` にする（例：`2026-10-20-ryusui-kakudo.md`）
   - ファイル名の英数字部分がURLになります。日本語は使わないでください
3. 【 】の部分を書き換えて、`_posts` フォルダにアップロード
4. 1〜2分で公開されます

写真は `assets/images` に入れ、記事の `image:` に書きます。スマホの写真は大きいので、横1600px程度に縮めてから入れてください。

## 下書き

公開したくない書きかけは `_drafts` フォルダに入れておけば、サイトには出ません。

## 守ること（このサイトの約束）

- 事実には出典を書く。町史などの文章はそのまま写さず、自分の言葉で
- 写真は撮影者・持ち主の許可を得る
- 聞き書きは、話し手に公開前の原稿を確認してもらい、同意を得た表記だけ載せる
- 直したら `updated:` に日付を入れる

## 任期後や町への引き継ぎ

すべての記事はこのリポジトリにテキストとして残ります。「Code」→「Download ZIP」で丸ごと取り出せるので、町や図書館に渡すときもこのZIPを渡せば済みます。
